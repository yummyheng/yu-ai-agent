# 工具族与注册设计

tools 包——Spring AI `@Tool` 注解工具族与集中注册面。

## 工具族清单（7 工具）

| 工具 | 行数 | 能力 | 外部依赖 |
| --- | --- | --- | --- |
| FileOperationTool | 30 | 文件读 / 写（双 @Tool 方法） | JDK |
| TerminalOperationTool | 25 | 终端命令执行（超时保护） | JDK Process |
| PDFGenerationTool | 34 | HTML→PDF 生成 | OpenHTMLToPDF |
| ResourceDownloadTool | 17 | 图片/音频资源下载（存 FileConstant 目录） | hutool HttpUtil |
| WebSearchTool | 36 | 网页搜索 | search-api（独立 api-key） |
| WebScrapingTool | 12 | 网页内容抓取 | jsoup |
| TerminateTool | 10 | 智能体终止信号（文本块 @Tool description——Java 21 语法） | 无 |

## 注册面（单点）

`ToolRegistration`（26 行，@Configuration）：`@ToolCallbackProvider` 方法 `tools()` 返回全部工具实例——**全工程唯一注册点**。

## 消费方（双入口同源）

| 消费方 | 注入形态 | 场景 |
| --- | --- | --- |
| YuManus（Agent域） | 构造器 `ToolCallback[] allTools` | ReAct 自主决策逐工具调用（act 面） |
| LoveApp#doChatWithTools | `@Resource ToolCallback[] allTools` | 单轮对话直挂工具 |

两消费方同一数组（Spring 注入 ToolRegistration 产物）——工具清单变化只动注册点一处。
