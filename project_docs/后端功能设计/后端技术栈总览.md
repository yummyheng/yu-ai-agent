# 后端技术栈总览

`yum-ai-agent-backend` 全量技术栈盘点（素材源：`pom.xml` + `application.yml` + 源码 import 实证，2026-10-09）。真源=依赖声明与源码引用，本文是导航视图。

## 全项目模块视图

| 模块 | 技术底座 | 说明 |
| --- | --- | --- |
| `yum-ai-agent-backend/` | Spring Boot 3.4.4 + Spring AI 1.0.0 | 主服务（8123），本文主体 |
| `yum-ai-agent-frontend/` | Vue 3.2 + Vue Router 4 + axios + @vueuse/head，Vite 4 构建（dev 3000 直连 8123） | SSE 聊天界面（前端栈详见 `../前端功能设计/前端架构设计.md`） |
| `yum-image-search-mcp-server/` | Spring Boot 3.4.5 + spring-ai-starter-mcp-server-webmvc + Hutool | 独立 MCP server 模块（图片搜索工具，P3 留批） |

## 语言与框架底座

| 层 | 技术 | 版本 | 用途/落点 |
| --- | --- | --- | --- |
| 语言 | Java | 21（pom `java.version`；本机 JDK 24 编 release 21） | 全模块 |
| 构建 | Maven | parent=`spring-boot-starter-parent` 3.4.4 | BOM 统辖 + spring milestones/snapshots 仓库 |
| Web | spring-boot-starter-web（MVC） | 3.4.4 | 端口 8123，context-path `/api`，CORS（`config/CorsConfig`） |
| AI 框架 | Spring AI | BOM 1.0.0（另有 spring-ai-alibaba-bom 1.0.0.2 导入但 starter 已注释退役） | ChatClient / Advisor 链 / ChatMemory / Tool Calling / RAG / MCP 六面全用它 |

## 模型接入面（现役/备选矩阵）

| 通道 | 依赖 | 状态 | 落点 |
| --- | --- | --- | --- |
| 智谱 GLM | `spring-ai-starter-model-zhipuai` | ★现役 | `application.yml` zhipuai 段：chat=glm-5.3-flash、embedding=embedding-3（key 占位符外置 `~/.orchestrator-secrets.yaml`）；zhipuaiChatModel/zhipuaiEmbeddingModel 单候选按类型注入 |
| 阿里 DashScope | `spring-ai-alibaba-starter-dashscope` | 注释态备选 | pom 注释块 + yml dashscope 注释段（切回=解注 + 换 starter） |
| Ollama 本地 | `spring-ai-starter-model-ollama` | 依赖在、自动装配排除 | demo 面（`OllamaAiInvoke` 手动 new）；exclude 避免双 ChatModel 候选撞注入点 |
| DashScope 原生 SDK | `dashscope-sdk-java` 2.19.1 | demo 对照面 | `HttpAiInvoke`（HTTP 裸调对照 Spring AI 抽象） |
| LangChain4j | `langchain4j-community-dashscope` 1.0.0-beta2 | demo 对照面 | `LangChainAiInvoke`（跨框架形态对照） |

## RAG 与向量存储

| 件 | 技术 | 状态 |
| --- | --- | --- |
| RAG 抽象 | `spring-ai-rag`（显式补齐，原由 alibaba starter 传递）+ `spring-ai-advisors-vector-store`（QuestionAnswerAdvisor） | 现役（doChatWithRag） |
| 文档加载 | `spring-ai-markdown-document-reader` | 现役（三篇恋爱知识库 md） |
| 向量库 | `SimpleVectorStore`（内存，builder 注入 EmbeddingModel） | ★现役（@Lazy 懒初始化——bean 创建期 AI 富化+向量化按 token 计费） |
| 向量库（备选） | `spring-ai-pgvector-store` + `postgresql` 驱动 + `spring-boot-starter-jdbc` | 依赖在、datasource 配置注释态 |

## MCP 面

- **client**：`spring-ai-starter-mcp-client`（依赖在；yml mcp.client 配置注释态——SSE/stdio 双形态，启用需先起 server）。消费点=`LoveApp.doChatWithMcp`（toolCallbackProvider 注入）。
- **server**：独立模块 `yum-image-search-mcp-server`（webmvc 传输；本工程是其 client 侧示例对端）。
