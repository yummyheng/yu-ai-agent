## 1. 概述

本文档描述 `yum-ai-agent` 后端（`yum-ai-agent-backend/src/main/java/com/yupi/yuaiagent/`，2026-10-09 源码重组自根 `src/` 挪入 yum-ai-agent-backend/（原 backend/））的对外接口。服务默认监听 `8123`，并通过 `server.servlet.context-path=/api` 对外暴露，因此文档中的路径均以 `/api` 为前缀。

前端开发环境 baseURL 为 `http://localhost:8123/api`（见 `yum-ai-agent-frontend/src/api/index.js`），生产环境为同域相对路径 `/api`。

## 2. 通用约定

### 2.1 响应结构

本项目**无统一响应包装**（无 ApiResponse 结构）：

- 同步端点直接返回 String 原文
- 流式端点返回 SSE（`text/event-stream`），逐 chunk 推送，前端以 `[DONE]` 标记判断结束（`connectSSE` 封装内约定）

### 2.2 参数命名

- 用户消息：`message`（query 参数）
- 会话 ID（恋爱大师多轮对话记忆键）：`chatId`

## 3. AI 恋爱大师接口（LoveApp）

实现：`controller/AiController.java` → `app/LoveApp.java`（含 RAG 知识库增强与对话记忆）。

四种流式形态为 Spring AI 时代的等价实现对照（Flux 原生 / ServerSentEvent 包装 / SseEmitter Servlet 侧），前端实际消费 §3.2。

### 3.1 同步对话

**接口URL**: `/api/ai/love_app/chat/sync`
**请求方法**: GET
**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| message | string | 是 | 用户消息 |
| chatId | string | 是 | 会话 ID（对话记忆隔离键） |

**响应数据**: `string`（完整回复原文，阻塞至生成结束）

### 3.2 SSE 流式对话（前端消费主入口）

**接口URL**: `/api/ai/love_app/chat/sse`
**请求方法**: GET（produces: text/event-stream）
**请求参数**: 同 §3.1

**响应数据**: SSE 流，逐 chunk 为回复增量文本，结束时发 `[DONE]` 标记。

前端封装：`chatWithLoveApp(message, chatId)`（`yum-ai-agent-frontend/src/api/index.js`）。

### 3.3 SSE 流式对话（ServerSentEvent 包装形态）

**接口URL**: `/api/ai/love_app/chat/server_sent_event`
**请求方法**: GET
**请求参数**: 同 §3.1

**响应数据**: `Flux<ServerSentEvent<String>>`——chunk 经 `ServerSentEvent` 包装（便于扩展 event/id 等元数据字段），数据体与 §3.2 等价。

### 3.4 SSE 流式对话（SseEmitter 形态）

**接口URL**: `/api/ai/love_app/chat/sse_emitter`
**请求方法**: GET
**请求参数**: 同 §3.1

**响应数据**: `SseEmitter`（Servlet 侧推送，超时 180000ms = 3 分钟）；内部订阅 Flux 转推，IO 异常走 `completeWithError`。

## 4. Manus 超级智能体接口

实现：`controller/AiController.java` → `agent/YuManus.java`（ReAct 模式自主智能体，可调用文件/终端/搜索/抓取/PDF/下载等工具）。

### 4.1 流式对话（智能体）

**接口URL**: `/api/ai/manus/chat`
**请求方法**: GET
**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| message | string | 是 | 任务指令（智能体自主拆解执行） |

**响应数据**: `SseEmitter` SSE 流——内容为智能体执行过程与最终回答的流式输出。每次请求新建 YuManus 实例（无跨请求记忆）。

前端封装：`chatWithManus(message)`。

## 5. 健康检查接口

### 5.1 存活探针

**接口URL**: `/api/health`
**请求方法**: GET
**请求参数**: 无

**响应数据**: 固定字符串 `ok`。
