## 二、AI 接口（冒烟豁免——人工联调面，SSE/纯文本响应不进自动冒烟）

前置：后端 8123 起服务 + application.yml 配置有效 dashscope api-key（现为占位符）。流式端点用 `curl -N` 关闭缓冲观测逐 chunk 输出与 `[DONE]` 结束标记。

```bash
# 同步对话（纯文本回复）
curl 'http://localhost:8123/api/ai/love_app/chat/sync?message=你好&chatId=test-1'
# SSE 流式（前端消费主入口）
curl -N 'http://localhost:8123/api/ai/love_app/chat/sse?message=你好&chatId=test-1'
# Manus 智能体流式
curl -N 'http://localhost:8123/api/ai/manus/chat?message=帮我搜索一些可爱的猫咪图片'
```
