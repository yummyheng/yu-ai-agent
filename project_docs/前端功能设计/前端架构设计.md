# 前端架构设计

## 技术栈与目录结构

Vite + Vue 3（`<script setup>` 组合式 API）+ Vue Router + axios（仅基座封装，SSE 用原生 EventSource）+ @vueuse/head（SEO）。

```
yum-ai-agent-frontend/src/
├── main.js              # 入口（createApp + router + head 挂载）
├── App.vue              # 根组件（router-view 容器）
├── router/index.js      # 3 路由
├── api/index.js         # API 封装（connectSSE 通用 SSE 连接 + chatWithLoveApp/chatWithManus）
├── views/               # 页面：Home / LoveMaster / SuperAgent
├── components/          # 组件：ChatRoom / AppFooter / AiAvatarFallback（HelloWorld 残留）
└── assets/
```

## 路由树

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | Home.vue | 落地页（特性导航 → 两 AI 页面） |
| `/love` | LoveMaster.vue | AI 恋爱大师（chatWithLoveApp） |
| `/super` | SuperAgent.vue | AI 超级智能体（chatWithManus） |

## 组件树

```
App.vue
├── Home ── AppFooter
├── LoveMaster ── ChatRoom（aiType=love）+ AppFooter
└── SuperAgent ── ChatRoom（aiType=super）+ AppFooter
ChatRoom ── AiAvatarFallback（头像加载失败兜底）
```

## SSE 消费链（核心数据流）

```
api/index.js#connectSSE(url, params)
    query 拼接 → new EventSource(fullUrl) → onmessage 逐 chunk（[DONE] 结束标记）
        ↓ 页面级持有（LoveMaster / SuperAgent 同构）
页面 sendMessage(message)
    eventSource.close() 旧连接 → addMessage('', false) 预占 AI 消息位（aiMessageIndex）
    → eventSource.onmessage: aiMessageIndex 定点增量拼接（打字机效果）
    → [DONE]: connectionStatus → disconnected + close
    → onerror: connectionStatus → error + close
        ↓ props 下传
ChatRoom（受控展示件：messages / connectionStatus / aiType + emit send-message）
```

关键设计事实：

1. **SSE 消费逻辑在页面级不在 ChatRoom**——ChatRoom 无任何 API 依赖，纯受控展示
2. **增量拼接而非追加消息**——`aiMessageIndex` 记住 AI 回复占位下标，chunk 到达定点改写该条 content
3. **每次发送先关旧连接**——单 eventSource 串行（不支持并发会话流）
4. **环境自适应 baseURL**——开发 `http://localhost:8123/api` / 生产同域 `/api`

## 依赖关系

- 后端契约：SSE 端点两枚（`/ai/love_app/chat/sse`、`/ai/manus/chat`）+ `[DONE]` 标记约定（真源见 `../api-docs/接口文档.md` §3.2/§4.1）
- 超时：axios 60s（非 SSE 面）；EventSource 由服务端 SseEmitter 超时兜底（180s/300s）
